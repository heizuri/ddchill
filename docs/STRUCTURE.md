# Organisation du projet

- `index.html` : page principale
- `css/` : feuilles de styles
- `js/` : scripts JavaScript
- `assets/` : images, vidéos et ressources locales
- `docs/` : documentation
- `vercel.json` : configuration du proxy RavenKoG

Ajouter chaque nouvelle fonctionnalité dans son propre fichier JavaScript sous `js/`.
