# DDChill

Site communautaire DDChill.

## Structure

- `index.html` : structure principale de la page
- `css/` : feuilles de styles externes
- `js/` : scripts modulaires
- `assets/` : images, vidéos et ressources locales
- `docs/` : documentation complémentaire
- `vercel.json` : configuration de déploiement et proxy RavenKoG

## Développement local

Servir le dossier avec n’importe quel serveur statique, par exemple :

```bash
npx serve .
```

Ouvrir ensuite l’adresse indiquée dans le navigateur.

## Scripts principaux

- `js/kog-stats.js` : statistiques RavenKoG
- `js/discord-auth.js` : connexion Discord
- `js/team.js` : affichage de l’équipe et compteurs Discord
- `css/team.css` : styles de l’équipe
